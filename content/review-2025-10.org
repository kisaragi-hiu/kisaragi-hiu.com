I've skipped many months, but I want to try to get back to this.

* Open source contributions

- Deno 2.5.5: Fix Deno's implementation of os.cpus() erroring on Android or when CPU info isn't available ([[https://github.com/denoland/deno/pull/31097][denoland/deno#31097]]). This is, however, unintentionally almost identical to [[https://github.com/termux/termux-packages/pull/26981][Termux's downstream patch]], which I didn't know existed when I [[https://github.com/denoland/deno/issues/25929#issuecomment-3448734941][investigated the issue for myself]]. The difference is that I concluded this change should apply to all platforms, since os.cpus() is specified in Node docs and implemented in Node to just return an empty array if it can't read CPU info.
